## Почему сборка невозможна в текущей среде

Для сборки Android APK требуются:
- Android SDK Platform (API уровня 21-34) - ~2-3 ГБ
- Android Build Tools - ~500 МБ
- NDK (Native Development Kit) - ~1 ГБ

Системный Android SDK в Ubuntu содержит только базовые инструменты
