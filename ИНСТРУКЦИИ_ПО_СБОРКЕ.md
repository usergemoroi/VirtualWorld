# Инструкции по сборке APK приложения VirtualWorld

## Обзор

Для сборки APK приложения VirtualWorld вам потребуется компьютер с Android Studio и полным Android SDK. В текущей среде сборка невозможна из-за отсутствия полных платформ Android API.

## Требования

- Windows, macOS или Linux компьютер
- Android Studio (последняя версия)
- Java JDK 17 или новее
- Не менее 8 ГБ оперативной памяти
- Не менее 10 ГБ свободного места на диске

## Пошаговая инструкция по сборке APK

### 1. Установка Android Studio

1. Скачайте Android Studio с https://developer.android.com/studio
2. Установите Android Studio
3. При первом запуске Android Studio предложит скачать Android SDK - согласитесь
4. После установки откройте Android Studio

### 2. Клонирование/открытие проекта

Если у вас еще нет проекта:

```bash
git clone <URL-вашего-репозитория>
cd VirtualWorld
```

Если у вас уже есть исходный код:

Просто откройте папку с проектом в Android Studio

### 3. Открытие проекта в Android Studio

1. Запустите Android Studio
2. Выберите "Open an Existing Project"
3. Выберите папку проекта `VirtualWorld`
4. Подождите пока Android Studio проиндексирует проект и загрузит зависимости Gradle

### 4. Сборка APK

#### Способ 1: Через Android Studio (рекомендуется)

1. В меню выберите: `Build` > `Build Bundle(s) / APK(s)` > `Build APK(s)`
2. Подождите пока завершится сборка
3. APK файл будет находиться в: `app/build/outputs/apk/debug/app-debug.apk`

#### Способ 2: Через командную строку

Перейдите в корневую папку проекта и выполните:

**Для Debug версии:**
```bash
./gradlew assembleDebug
```

**Для Release версии:**
```bash
./gradlew assembleRelease
```

APK файл будет находиться в:
- Debug: `app/build/outputs/apk/debug/app-debug.apk`
- Release: `app/build/outputs/apk/release/app-release.apk`

### 5. Установка APK на Android устройство

#### Через USB

1. Переведите телефон в режим "Разработчик" (Developer Options)
2. Включите "USB-отладку" (USB Debugging)
3. Подключите телефон к компьютеру через USB
4. Скачайте APK на телефон или используйте команду adb:

```bash
adb install app/build/outputs/apk/debug/app-debug.apk
```

#### Передача файла на телефон

1. Передайте APK файл на телефон (через USB, облачное хранилище, email и т.д.)
2. На телефоне откройте файл APK
3. При запросе разрешите установку из неизвестных источников

## Возможные проблемы и решения

### Проблема: Gradle синхронизация не завершается

**Решение:**
1. Откройте `File` > `Settings` > `Build, Execution, Deployment` > `Build Tools`
2. Убедитесь, что выбран правильный JDK
3. Нажмите "Apply" и "OK"
4. Попробуйте снова `File` > `Sync Project with Gradle Files`

### Проблема: Ошибка SDK location not found

**Решение:**
1. Откройте `File` > `Project Structure`
2. Перейдите в `SDK Location`
3. Укажите путь к вашему Android SDK
4. Нажмите "Apply"

### Проблема: SDK license not accepted

**Решение:**
1. Откройте терминал
2. Перейдите в папку Android SDK
3. Выполните:
   ```bash
   sdkmanager --licenses
   ```
4. Примите все лицензии (нажмите 'y' для каждой)

### Проблема: Ошибка зависимости

**Решение:**
1. Откройте терминал в корне проекта
2. Выполните:
   ```bash
   ./gradlew clean
   ./gradlew build --refresh-dependencies
   ```

## Краткое описание приложения

Приложение VirtualWorld - это Android приложение с использованием:
- Jetpack Compose для UI
- Kotlin для разработки
- Hilt для внедрения зависимостей
- Firebase для аутентификации и бэкенда
- Retrofit для сетевых запросов
- Room для локальной базы данных
- Material Design для компонентов UI

## Поддержка

Если у вас возникнут проблемы при сборке, проверьте:
1. Версию JDK (должна быть 17+)
2. Переменные окружения JAVA_HOME и ANDROID_HOME
3. Доступ в интернет для загрузки зависимостей Gradle
4. Достаточно свободного места на диске

## Примечания

- Debug APK содержит отладочные символы и больше по размеру
- Release APK оптимизирован и меньше, но требует подписи для публикации
- При первом запуске приложение запросит необходимые разрешения
