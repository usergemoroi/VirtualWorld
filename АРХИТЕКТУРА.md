# Архитектура VirtualWorld

## Обзор

VirtualWorld построен как модульный Android-проект, где UI отделён от ядра виртуализации. Цель — обеспечить клонирование APK, управление виртуальными процессами и BlackBox-контроль внутри песочницы.

## Модули

### app

- `MainActivity` — список виртуальных приложений.
- `AddAppActivity` — установка APK в виртуальную среду.
- `SettingsActivity` — управление root-режимом.
- `AppListAdapter` — вывод списка приложений.

### core

- `VirtualCore` — точка входа, инициализация окружения.
- `VEnvironment` — каталог виртуальной файловой системы.
- `VAppManager` — установка APK и хранение метаданных.
- `VProcessManager` — учёт виртуальных процессов.
- `VPackageManager` — поиск данных о пакетах.
- `VActivityManagerService` — запуск/остановка виртуальных приложений.
- `HookFramework` — система перехватов.
- `VirtualFileSystem` — эмуляция root и UID.
- `PermissionController` — контроль разрешений (BlackBox).

## Нативный слой

JNI-модуль (`core/src/main/cpp`) содержит заглушки для движка хуков и перенаправления IO. Его можно расширять для реальных системных перехватов.
